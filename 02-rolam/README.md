# Bemutatkozó profil (rólam szekció)
- Gyakorlat

Eza kis projekt a személyes bemuatkozó oldalam alapja. A célom az volt, hogy gyakoroljam a modern HTML5 és CSS3 elrendezési technikáit, miközben egy vizuálisan vonzó "Rólam" szekciót hozok létre.

## Megvalósítasi technikai megoldások:
* **Flexbox elrendezés:** A kép és a stöveg dinamikus egymás mellé rendezve `display: flex` használatáva.
* **Profilkép formázasa:** Kerekített profilkép létrehozása `border-radius: 50%` és `object-fit: coiver;` segítségével a torzítás mentes megjelenítésért.
* **Vizuális stílus:** Egyedi keretek (zöld és kék border) és sormagasság (`line-height`) beállítás a jobb olvashatóság érdekében.
* **Full-stack felkészülés:** A kód felépítése során figyeltem a tiszta szematikus HTML struktúrára, ami a későbbi Java fejlesztéseim alapja lesz.

## Hogyan néz ki?
A projekt egy reszponzív blokkot tartalmaz, ahol a leírás mellett egy stílusps, kör alakú keretben látható a profil képem. (AI generátl kép).
