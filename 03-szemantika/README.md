# 03 Szemantikus HTML gyakorlat

Egyszerű gyakorló projekt a szemantikus HTML és alap CSS használatára

## Tartalom
- HTML5 szemantikus elemek (`header`, `main`, `section`, `footer`)
- Navigáció anchor linkekkel
- Beágyazott vidó és audio
- Alap CSS (`flexbox`, `layout`, `hover`)

## Cél
Gyakorlás és alapok megerősítése
