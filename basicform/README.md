# Modern Űrlap Választólista
- Gyakorlat

Ez a projekt a HTML űrlapok (form) és a testreszabott legördülő menük(Select) stílusozását mutatja be. A cél a felhasználói élmény javítása volt modern CSS technikával.

## Főbb jellemzők:
* **Interaktív elemek:** a `:focus` állapot használata, amely zöld kerettel és finom árnyékkal jelzi az aktív beviteli mezőt.
* **Modern Desing:** Lekerekített sarkok (`border-radius`), egyedi kék keretek és tiszat háttérszínek.
* **Strukturált felépítés:** A `display: block` és a margók használata a mezők közötti átlátható távolságért.
* **Full-stack alapozás:** Ez a modul az alapja a későbbi Java-alapú adatbekérő rendszereimnek.

## Felhasznélt technológiák:
* HTML5 (Strukturált űrlap elemek)
* CSS3 (Box-shadow, Focus states, Flexbox alapok)
